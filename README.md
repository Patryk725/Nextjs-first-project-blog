## Getting Started

### Set variables in `.env` and `.env.docker` (just remove `.example` from filename)

### Run the development server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

### Open [http://localhost:3000](http://localhost:3000).
